## 快速开始

### 环境要求

| 要求 | 版本 |
| :--- | :--- |
| JDK | 17+ |
| Maven | 3.6+ |
| Spring Boot | 4.0.6 |

### 基础配置

在 `pom.xml` 中添加依赖管理：

```xml
<parent>
    <groupId>cn.structured</groupId>
    <artifactId>structure-dependencies</artifactId>
    <version>1.4.4</version>
</parent>
```
